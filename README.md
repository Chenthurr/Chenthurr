## 🚀 SELECTED PROJECTS

### 👁️ Real-Time Computer Vision Queue Management

A real-time vision system for detecting people inside a defined region and maintaining stable queue counts.

- YOLOv8 + OpenCV detection pipeline
- Polygon-based Region of Interest logic
- Custom centroid tracking
- Occlusion-tolerant debounce
- Moving-average smoothing
- FastAPI integration
- Reported **<5% error rate** despite momentary detection noise

**Stack:** `Python` `OpenCV` `YOLOv8` `FastAPI`

---

### 🏦 Loan Approval Prediction

An end-to-end machine learning workflow for automated loan assessment.

- Dataset containing **10,000+ records**
- Reported **~87% classification accuracy**
- Feature engineering and hyperparameter tuning
- 5-fold cross-validation
- SQL-based data extraction
- AWS-ready model evaluation workflow
- Reported **~40% reduction in manual review time**

**Stack:** `Python` `Pandas` `NumPy` `Scikit-learn` `TensorFlow` `SQL`

---
