# Contributing

This repository contains the GitHub profile configuration and generated profile assets.

## Guidelines

- Keep profile content concise, accurate, and accessible in both light and dark themes.
- Prefer deterministic, reproducible workflows for generated assets.
- Do not commit secrets, personal credentials, or generated files that are not used by the profile.
- Validate Markdown and workflow YAML before pushing changes.

## Changes

For profile or automation updates, make the smallest focused change possible and verify the rendered README and relevant GitHub Actions workflow before merging.
